# Swooshz Design

AI-assisted exhibition-booth concept studio.

## MVP

The full-suite MVP turns a structured booth brief into four concepts, QA/repair, selection/refinement, a final hero, a Concept Layout Plan, an accepted canonical spatial model, coherent review views, and downstream CAD/3D handoff.
